
# Food Delivery Analytics

## Project Overview
This project analyzes food delivery orders to understand platform revenue, delivery performance, customer ratings, cuisine demand, and order patterns.

## Tools Used
- Microsoft Excel
- MySQL
- SQL

## Dataset
- Total Orders Analyzed: 5,000
- Food Delivery Platforms: Zomato and Swiggy
- Analysis includes order value, delivery time, restaurant ratings, cuisine, and locality.

## Key Performance Indicators
- Total Revenue: ₹13,76,255.85
- Zomato Revenue: ₹7,74,113.32
- Swiggy Revenue: ₹6,02,142.53
- Average Delivery Time: 39.62 minutes
- Average Restaurant Rating: 4.15

## Key Insights
- Zomato generated higher total revenue than Swiggy in this dataset.
- Average delivery times were similar across both platforms.
- North Indian cuisine had the highest number of orders.
- January had more orders than February in the available data.

## Project Files
- Excel workbook: Dashboard and business analysis
- SQL file: Queries used for data analysis
